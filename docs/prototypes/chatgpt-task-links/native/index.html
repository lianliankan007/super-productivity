  1. 左侧是直接从 fork 源码构建的 Super Productivity，可以照常使用任务、日程、计划、专注、统计和设置。
  2. 原版新安装默认关闭部分功能。点击“原生功能设置”可开启日程、看板、习惯和专注模式，修改会自动保存。
  3. 首次使用点击“启用本机关联插件”，在左侧原生安装确认框中确认；也可以下载 ZIP，在设置 → 插件中手动安装。
  4. 连接后点击“添加示例任务”，创建真实的原生项目、主任务和子任务，或直接使用你在本站点新建的任务。
  5. 从会话侧关联或创建子任务；点击“在原应用中查看”定位原生任务。原生任务的链接附件可打开对应会话。
  6. ChatGPT 一侧仍为本地模拟，没有连接真实 ChatGPT 账号或语言模型。此站点的原生任务保存在浏览器 IndexedDB，与旧原型的数据分开。
